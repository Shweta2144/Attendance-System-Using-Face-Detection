Developed an automated real-time Attendance System using Python, OpenCV, and DeepFace, replacing traditional manual sign-ins and eliminating proxy attendance.

Integrated an SQLite database to efficiently store and manage user credentials, profile details (such as enrollment and contact info), and automated timestamped attendance logs.

Designed a user-friendly interface and system workflow featuring user registration, real-time face detection via webcam, and automated record-matching to streamline administrative tracking.
